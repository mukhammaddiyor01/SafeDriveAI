# Galaxy A51 qurilma sinovi

Bu tekshiruvlarni haydamasdan, telefon mahkamlangan va avtomobil to‘xtagan holatda bajaring.
Model, Android versiyasi, yorug‘lik, tutqich burchagi, APK versiyasi va natijani yozib boring.

| Tekshiruv | Kutiladigan natija |
|---|---|
| Kamera ruxsatini rad etish | Tushunarli xabar, qayta urinish mumkin |
| Alarm ovozi nol | Boshlashdan oldin ovozni oshirish haqida xabar |
| Signalni sinash | Qisqa ovoz va vibratsiya; keyin o‘chadi |
| Oddiy qisqa ko‘z yumish | Alarm yo‘q |
| 1.5 s davomli ko‘z yumish | Kechikishsiz alarm; real kechikishni o‘lchang |
| Ko‘zlar yana ochilishi | Signal o‘chadi, holat yangilanadi |
| Yuz yonboshga burilishi | Ko‘z ma’lumoti yo‘q, limited; uzoq holatda ogohlantirish |
| Yuz kameradan chiqishi | Limited va taxminan 3 s dan keyin signal |
| Ikki odam kadrga kirishi | Limited, haydovchi o‘zboshimchalik bilan tanlanmaydi |
| Home tugmasi | Bildirishnoma qoladi, tahlil va alarm davom etishini tekshiring |
| Ekran o‘chishi 5–15 daqiqa | Kamera va alarm davomiyligini qurilmada tekshiring |
| Bildirishnomadan Stop | Kamera, ovoz, vibratsiya va service to‘xtaydi |
| Activity’ni qayta ochish | Ishlayotgan service holati ekranga qaytadi |
| Android Force stop | Kuzatuv to‘xtaydi; avtomatik qayta ishga tushmaydi |
| Qo‘ng‘iroq, DND, boshqa kamera | Kamera/ovoz ustuvorliklari va cheklovlar qayd etiladi |
| ChatGPT yoqilgan va USB server ishlayapti | Inglizcha eslatma va xavfsiz to‘xtash haqida savol; manba ChatGPT |
| Server yo‘q yoki USB uzildi | Mahalliy inglizcha eslatma; alarm uzilmaydi |
| Inglizcha TTS yo‘q | Ovoz mavjud emasligi ko‘rsatiladi, alarm ishlaydi |
| 30–60 min kuzatuv | FPS, qizish, quvvat sarfi va yolg‘on alarmni o‘lchang |

Avtomatlashtirilgan testlar bu qurilma sinovining o‘rnini bosmaydi. Hozircha Galaxy
A51’dagi haqiqiy kamera/background natijalari qayd etilmagan.
